# Roadmap de Lobot

Este documento describe la hoja de ruta planeada para el desarrollo de Lobot.

## Estado Actual

✅ **v0.1.0 - Base Foundation** (Completado)
- Estructura base del proyecto Unity/Android
- Integración completa con Ollama API
- Sistema de gestión de modelos
- Componentes UI básicos
- Puente nativo Android
- Estructura ROS2 (placeholder)
- Documentación completa
